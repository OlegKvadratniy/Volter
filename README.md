# Volter

Taobao parser with GUI for order management and Excel export.

## Stack
- Python 3.11+
- PySide6 (GUI)
- Playwright (parsing)
- deep-translator (translation)
- openpyxl (Excel export)

## Setup
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install
```
